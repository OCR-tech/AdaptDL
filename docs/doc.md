# AdaptDL: Real-Time Object Detection with Voice Commands

## Overview

AdaptDL is a Python-based real-time object detection system powered by deep learning. It features voice command integration and instant voice feedback for surveillance applications.

## Key Features

- **High Accuracy**: Advanced deep learning models for robust and precise object detection.
- **Voice Commands & Alerts**: Supports voice commands for hands-free control and instant voice alerts.
- **User-Friendly Interface**: Offers an intuitive graphical user interface for easy interaction.
- **Real-Time Processing**: Processes video streams in real-time, ensuring immediate detection and feedback.
- **Flexible Input Sources**: Supports webcam, USB camera, IP camera, and video file inputs.
- **Web-Based Interface**: A browser-based demo for real-time object detection.

## Getting Started

1. Clone the repository and install dependencies.
2. Start the application and open `app/web/index.html` in your browser.
3. Grant camera and microphone permissions when prompted.
4. Use voice commands or keyboard shortcuts to interact with the system.
